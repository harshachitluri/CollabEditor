# Production Roadmap & Quick Commands

Purpose: a single-file reference to stage, build, verify, and release CollabEditor.

Prerequisites
- Node.js & npm installed (matching project versions)
- PostgreSQL or configured database for Prisma (if used)
- Environment variables set locally or in CI: see `ENV VARS` section

Quick local commands
- Backend (dev):
  - npm --prefix backend run dev
  - npm --prefix backend run build
  - npm --prefix backend run start
- Frontend (dev):
  - npm --prefix frontend run dev
  - npm --prefix frontend run build
  - npm --prefix frontend run start

Lint & format
- Backend:
  - npm --prefix backend run format
  - npm --prefix backend run lint
- Frontend:
  - npm --prefix frontend run format
  - npm --prefix frontend run lint

Database / Migrations (Prisma)
- Apply migrations (production/staging):
  - cd backend && npx prisma migrate deploy
- Dev migrate & reset (local):
  - cd backend && npx prisma migrate dev
  - cd backend && npx prisma db push
  - cd backend && npx prisma studio

Environment variables (example)
- In `.env` or your deployment secrets store:
  - DATABASE_URL=postgres://user:pass@host:5432/dbname
  - JWT_SECRET=your_jwt_secret
  - NEXT_PUBLIC_API_URL=https://api.example.com
  - CLIENT_URL=https://app.example.com

Security & secrets
- Remove secrets from repo. Use environment/secret manager (Vault, GitHub Secrets).
- Run `npm audit` in both `backend` and `frontend` and address high/critical issues.

Docker (local staging)
- Example workflow (create Dockerfiles first):
  - docker compose up --build
  - docker compose logs -f

Release & deploy
- Create release branch and tag:
  - git checkout -b release/v1.0.0
  - git commit -am "chore: release v1.0.0"
  - git tag -a v1.0.0 -m "v1.0.0"
  - git push origin release/v1.0.0 --tags

PM2 / systemd (example)
- PM2: use `deploy/pm2/ecosystem.config.cjs`
- systemd: install `deploy/systemd/collab-backend.service` and `deploy/systemd/collab-frontend.service`
- Production scripts:
  - `npm --prefix backend run start:prod`
  - `npm --prefix frontend run start:prod`

Smoke test checklist (manual)
1. Start backend and frontend in production mode.
2. Visit app home page, ensure theme loads and no console errors.
3. Sign in / create account; verify dashboard loads rooms.
4. Create a room, open it in two browsers (or incognito + normal).
5. Confirm code changes sync bi-directionally.
6. Confirm live cursors appear with different colors and labels.
7. Run code in the room and confirm output shows in terminal panel.
8. Open chat, send messages; confirm messages broadcast.

Troubleshooting tips
- If editor fails to load: ensure `@monaco-editor/react` is not SSR-imported.
- If sockets don't connect: check `NEXT_PUBLIC_API_URL` and CORS on backend.
- If cursors aren't visible: confirm backend emits `cursor-move` and frontend receives it.
